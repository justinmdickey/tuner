# Tuner

A guitar and ukulele tuner that is just a tuner. No ads, no analytics, no accounts,
no network requests after it loads. Installs as a PWA and works offline.

Live at [tuner.erisdor.com](https://tuner.erisdor.com).

## Why

Every free tuner app is either full of ads or wants an account. This is ~35 KB of
vanilla JavaScript.

## Modes

- Guitar standard — E2 A2 D3 G3 B3 E4
- Ukulele standard (reentrant) — G4 C4 E4 A4
- Ukulele low-G — G3 C4 E4 A4
- Chromatic — nearest 12-TET note

It detects which string you are playing, shows the deviation in cents on a needle,
and flags in-tune within ±5 cents with both a badge and a visual change (not colour
alone). Each string has a reference tone.

## How the pitch detection works

`pitch.js` implements the McLeod Pitch Method: a normalized square difference
function (NSDF) over the lag range covering 60–1400 Hz, with parabolic interpolation
around the chosen peak for sub-sample period resolution.

The interesting problem is octave errors. A plucked low E often has a **second
harmonic louder than its fundamental**, so a detector that simply takes the strongest
correlation peak reports E3 instead of E2 — this is why cheap tuners jump an octave
on the low string. The fix here is to pick the *first* NSDF maximum that reaches 90%
of the global peak rather than the global peak itself, which prefers the lowest
plausible period. NSDF is used instead of plain autocorrelation precisely because its
normalization makes that 90% comparison amplitude-independent.

Detection is gated on RMS (silence returns null) and on peak clarity (unpitched noise
returns null).

The module is deliberately free of DOM and Web Audio references so it can be tested
without a microphone.

## Tests

```sh
bun test
```

42 tests covering pure sines and 7-harmonic plucked waveforms at every open string in
every tuning at both 44.1 and 48 kHz, a 60→1400 Hz sweep, deliberate
louder-harmonic octave traps, noise gating, and detection under realistic SNR.
Everything must land within 1 cent. CI runs this before building the image.

## Notes for hacking on it

- Mic capture disables `echoCancellation`, `noiseSuppression` and `autoGainControl`.
  Chrome's voice processing mangles a string's harmonic content and ruins detection.
- **Bump `CACHE` in `sw.js` on any file change**, or installed clients keep serving
  the old shell from cache.
- Requires HTTPS in practice: `getUserMedia` and service workers need a secure
  context (localhost is exempt).
- Icons are generated by `tools/make-icons.js` — a zero-dependency PNG encoder, so
  there is nothing to install.

## Deployment

Runs on a k3s cluster via Flux; manifests live in a separate private
`kubernetes-homelab` repo. Pushing a `v*.*.*` tag builds and publishes
`ghcr.io/justinmdickey/tuner`, and Flux image automation rolls the cluster forward on
its own.
